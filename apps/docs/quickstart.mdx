title: "Quickstart"
description: "Start with the Repin web workspace and browser extension."
---

Repin has two client surfaces that use the same account and backend data:

- The web workspace stores conversations, bookmarks, notes, highlights,
  memories, and assistant activity.
- The browser extension provides contextual assistance on the active page and
  executes connected-browser tools.

## Start in the web workspace

After Repin is installed, open the web application and create an account. Use
the dashboard to start a conversation or open saved content.

## Connect the extension

Open the Repin extension popup and begin authorization. The extension opens the
web application's authorization page, where you approve the connection for the
signed-in account.

## Use page context

Open the Repin sidebar on a webpage or select text to use the available
contextual actions. Saved bookmarks, notes, and highlights remain available in
the web workspace.

For a local installation, follow [Install with Docker](/installation/docker)
and [Install the browser extension](/installation/browser-extension).
