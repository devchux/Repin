Repin connects a durable AI workspace with the page you are currently browsing.
Use it to understand content, retain useful knowledge, and complete browser
tasks with visible execution and approval boundaries.

## What Repin can do

- Explain selected text and answer questions about the active page.
- Summarize articles and translate selections.
- Save bookmarks, notes, highlights, and durable memories.
- Continue persistent conversations between the web app and extension.
- Execute managed or connected-browser tools with approvals for consequential actions.

<Note>
Repin is under active development. Browser autonomy expands incrementally as
permission, recovery, and evaluation safeguards mature.
</Note>
